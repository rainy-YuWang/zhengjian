## 启动

要求 Node.js 24+、npm。不需要数据库或 API Key。

```bash
npm ci
npm run dev
```

默认端口 5173。在 Windows 上若 Cloudflare workerd 出现运行时兼容错误，使用独立 Node 预览：

```powershell
$env:LOCAL_NODE_PREVIEW='1'
npm run dev
```

macOS/Linux 同等命令：`LOCAL_NODE_PREVIEW=1 npm run dev`。此变量只作用于 serve；生产构建保留 Sites 和 Cloudflare 集成。生产构建运行 `npm run build`，输出 dist/server/index.js 及客户端资源。

```bash
node --experimental-strip-types --test tests/engine.test.mjs tests/api.test.mjs
npx tsc --noEmit
npm run build
```

已提供 package-lock.json。无须安装 README 所用 Markdown 工具。

## 两分钟体验

1. 点击“利润与现金流是否相互印证？”：系统选择经营质量、财务趋势，调取支持、压力和矛盾证据。
2. 打开 E02：查看报告期、单位、原始金额、页码链接、公式和不能说明的结论；再交叉阅读毛利率证据。
3. 将待验证问题加入研究清单，在研究笔记中编辑、勾选或导出。
4. 财务趋势切换 2026前三季度 / 2025全年 / 2024全年。所有对比均同期间，不年化季度数据。
5. 估值与行情输入假设价格 1313.2：静态PE情景为20倍；这不是市场价格或TTM。
6. 在产品说明中打开“演示接口失败”，再提问：界面明确显示降级，不伪装为在线模型结果。

## 产品与 AI 分工

当前交付版本没有配置在线模型凭据。可运行主链路采用：规则选择维度 → 确定性计算 → AI参与撰写并经来源核验的证据解读 → 用户继续验证。界面明确标注“已核验AI解读”，不会伪装实时生成。

可选服务端模型适配器已实现：POST /api/diagnose。设置 OPENAI_API_KEY 和 OPENAI_MODEL 后，通过 Responses API 从当前候选证据ID中选择并排序。模型不计算财务数字，不提交任意自由文本；后端拒绝空、重复、伪造、越界ID。模型失败、超时、返回无效结构均回退至核验快照并返回明确状态。在线模型的真实外部调用未经验证；已用 mock 覆盖成功、失败与无效证据返回。

环境变量示例见 .env.example。密钥只能存服务端或部署平台的 secret，不能进入浏览器、Git或快照。运行时不存储问题，也不上传研究笔记；配置模型后，仅研究问题和候选证据标题发送至所配置的 OpenAI 服务。

## 数据与计算

来源为公司官网正式披露与巨潮资讯公告；链接、发布时间、期次、页码、审计状态均保存在 lib/data.mjs。来源明细见 docs/DATA_SOURCES.md。财务数据原始单位为人民币元，保留原披露小数后计算，再转换为亿元显示。

- 同比：(本期 / 同期 − 1) × 100%；非正分母不计算增长率。
- 营业毛利率：(营业收入 − 营业成本) / 营业收入；不混入财务公司利息收入。
- 归母净利率：归母净利润 / 营业收入；非合并净利率。
- 现金利润比：合并经营现金流 / 归母净利润，仅作观察；合并现金流含财务公司。
- 直销占比：直销 / (直销 + 批发代理)，原始万元乘10000转换为元。
- 估值情景：用户假设价格 / 2025全年基本EPS 65.66；不输出实时估值或价格目标。
- 本地CSV：date,close；2–2000条、200KB内、日期严格递增、价格有限且大于0。区间价格收益和收盘最大回撤由原始序列计算，非含分红总回报。

## 边界与未做事项

只支持一家主诊断公司；同行观察含贵州茅台和泸州老窖两家公司，不能推导行业排名或市占率。五粮液等其他公司不套用茅台数据。当前问答库不支持开放领域事实问答，仅选择已有证据；其他问题会回到基础研究维度，用户可在财务页切换历史期间。

扶摇文档本次访问失败，iFinD MCP未连接；不声称调用过这些服务。没有实时行情、历史估值分位、批价、独立终端动销、独立渠道库存或剔除财务公司的现金流。未执行所有最新公告的完整性扫描。年度快照缺少营业成本，毛利率显示“未收录”。外部PDF链接可能日后变更，快照并非实时数据管道。

CSV由用户确认标的与复权口径，系统不校验交易日历或数据真伪；导入数据只存在当前页面内存。研究笔记保存在当前浏览器localStorage，清理浏览器或更换设备不会同步。没有账户、持仓、订单、订阅或买卖操作；无视频交付。

公开站点根据用户明确选择发布；源仓库访问权限独立于站点访问权限。
